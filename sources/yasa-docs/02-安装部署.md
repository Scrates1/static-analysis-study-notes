# 安装部署

⚠️ 重要前提： YASA-Engine 是一个独立的安全分析引擎，但对 Go 和 Python 的解析能力依赖于 YASA-UAST 提供的二进制工具（uast4go / uast4py）。Js 解析直接集成在YASA-Engine里面，因此不提供单独的二进制文件。

[[CARD_01]]

[[CARD_02]]
```plain
目前开源出来的YASA包括
YASA-Engine与YASA-UAST

您可以：
1. 获取 YASA-Engine 发布包，包含了YASA-Engine与YASA-UAST的RELEASE二进制
2. 获取源码自主构建
2.1 获取 YASA-Engine 源码，自主构建YASA-Engine二进制
2.2 获取 YASA-UAST 源码，构建 uast4go、uast4py 二进制/发布uast-java-js npm包
2.3 将两者组合成一个运行目录
2.4 调用 YASA-Engine 进行测试
```

[[CARD_03]]
🔧 第一部分：如何获取或者构建YASA-Engine
✅ 场景一：直接下载YASA-Engine与YASA-UAST Release合集（推荐）
步骤 1：访问 Engine 的 Release 页面
👉 https://github.com/antgroup/YASA-Engine/releases
选择目标版本，如 v0.1.22
步骤 2：下载对应平台的 ZIP 包
全屏复制
|
文件名
|
适用平台
|
yasa-linux-x64.zip
|
Linux x86_64
|
yasa-macos-x64.zip
|
macOS Intel
|
yasa-macos-arm64.zip
|
macOS Apple Silicon
示例（Linux 用户）：

[[CARD_04]]
```plain
wget https://github.com/antgroup/YASA-Engine/releases/download/{版本号}/yasa-linux-x64.zip
```
步骤 3：解压并进入目录

[[CARD_05]]
```plain
unzip yasa-linux-x64.zip -d yasa-bundle
cd yasa-bundle
```
查看内容：

[[CARD_06]]
```plain
ls -l
```
你应该看到：

[[CARD_07]]
```plain
yasa-engine-linux-x64 # 主程序
node_modules/ # 内置 JS 依赖
uast4go-linux-amd64 # 可选：Go 解析器
uast4py-linux-amd64 # 可选：Python 解析器
sha256sum.txt # 校验文件
```
步骤 4：赋予执行权限

[[CARD_08]]
```plain
chmod +x yasa-engine-* uast4go-* uast4py-*
```

[[CARD_09]]
✅ 场景二：从源码构建 YASA-Engine（适合调试或二次开发）
前提条件
Nodejs ≥18
npm
typescript ≥5.8.3
pkg 工具：npm install -g pkg
步骤 1：克隆仓库

[[CARD_10]]
```plain
git clone https://github.com/antgroup/YASA-Engine.git
cd YASA-Engine
```
步骤 2：安装依赖

[[CARD_11]]
```plain
npm install
```
✅ 确保网络通畅，能下载 @ant-yasa/uast-spec 和 @ant-yasa/uast-parser-java-js
步骤 3：编译ts文件（使用 tsc）

[[CARD_12]]
```plain
npx tsc
```
✅ 建议打包完之后删除dist下的文件，不然可能会影响mocha的单测回归执行
步骤 4：构建可执行文件（使用 pkg）
pkg . --options max-old-space-size=13312（V8最大内存分配13G，否则默认只有4G） 生成所有二进制，或者按照下面操作系统生成
Linux (x64)

[[CARD_13]]
```plain
npx pkg . --options max-old-space-size=13312 --target node18-linux-x64 --output dist/yasa-engine-linux-x64
```
macOS (Intel)

[[CARD_14]]
```plain
npx pkg . --options max-old-space-size=13312 --target node18-macos-x64 --output dist/yasa-engine-macos-x64
```
macOS (Apple Silicon)

[[CARD_15]]
```plain
npx pkg . --options max-old-space-size=13312 --target node18-macos-arm64 --output dist/yasa-engine-macos-arm64
```
✅ 构建成功后，dist/ 目录下会有一个单独的可执行文件。
步骤 5：手动打包完整 Bundle（建议做法）
为了便于分发，建议将主程序 + 依赖 + UAST 二进制合并为一个目录。

[[CARD_16]]
```plain
mkdir my-release-bundle
cp dist/yasa-engine-linux-x64 my-release-bundle/
cp -r node_modules my-release-bundle/

# 复制你之前构建好的 UAST 二进制
cp ../YASA-UAST/parser-Go/dist/uast4go-linux-amd64 my-release-bundle/
cp ../YASA-UAST/parser-Python/dist/uast4py-linux-amd64 my-release-bundle/

# 生成校验文件
(
cd my-release-bundle
> sha256sum.txt
for f in *; do
if [ -f "$f" ]; then
sha256sum "$f" >> sha256sum.txt
fi
done
)

# 打包
zip -qr yasa-custom-linux-x64.zip my-release-bundle/
```
现在你可以把这个 ZIP 分发给其他人使用了！

[[CARD_20]]
✅ 场景二：本地研发&构建 UAST Go/Python解析器 （开发）
前提条件安装
确保已安装：
Go ≥1.21: https://golang.org/dl/
Python ≥3.13（仅构建 uast4py）
PyInstaller: pip install pyinstaller
Docker（仅构建 Linux 版 uast4py）
步骤 1：克隆仓库

[[CARD_21]]
```plain
git clone https://github.com/antgroup/YASA-UAST.git
cd YASA-UAST
```

[[CARD_22]]
构建 uast4go（Go 解析器）
Linux (amd64)

[[CARD_23]]
```plain
cd parser-Go
GOOS=linux GOARCH=amd64 go build -o dist/uast4go-linux-amd64 .
```
macOS (Intel)

[[CARD_24]]
```plain
GOOS=darwin GOARCH=amd64 go build -o dist/uast4go-mac-amd64 .
```
macOS (Apple Silicon)

[[CARD_25]]
```plain
GOOS=darwin GOARCH=arm64 go build -o dist/uast4go-mac-arm64 .
```
✅ 构建完成后，将生成的二进制复制到你的运行环境中备用。

[[CARD_26]]
构建 uast4py（Python 解析器）
方法 A：Linux 平台（使用 Docker 容器构建）

[[CARD_27]]
```plain
# 在 YASA-UAST 根目录执行
docker build \
--build-arg GOOS=linux \
--build-arg GOARCH=amd64 \
-f parser-Python/Dockerfile.linux \
-t uast4py-linux .

# 创建容器提取产物
docker create --name temp-container uast4py-linux
mkdir -p dist
docker cp temp-container:/dist/uast4py-linux-amd64 dist/uast4py-linux-amd64
docker rm temp-container

# 添加可执行权限
chmod +x dist/uast4py-linux-amd64
```
方法 B：macOS 原生构建（Intel 或 M1/M2）

[[CARD_28]]
```plain
cd parser-Python
python -m venv .venv
source .venv/bin/activate

pip install -r requirements.txt
pip install pyinstaller

pyinstaller --onefile uast/builder.py

# 重命名并整理
mv dist/builder dist/uast4py-mac-amd64
chmod +x dist/uast4py-mac-amd64
```
如果你在 ARM 架构 Mac 上运行，生成的就是 arm64 版本。

[[CARD_29]]
✅ 构建完成后，你会得到如下关键文件：

[[CARD_30]]
```plain
parser-Go/dist/
└── uast4go-{platform}-{arch}

parser-Python/dist/
└── uast4py-{platform}-{arch}
```
请妥善保存这些二进制，后续会被 YASA-Engine 调用。

✅ 场景三：本地研发&发布UAST SPEC 与UAST Java-Js 解析器（开发）
⚠️ 本节适用于需要 脱离 GitHub Actions 自行发布 NPM 包 的开发者或项目维护者。
若你只是使用 YASA-UAST，无需执行以下操作；
若你是团队成员需参与发布，则请严格按此流程操作。

[[CARD_31]]
若你是测试验证，建议在npm上创建自己的工作空间替换，而不是直接推送至npm的ant-yasa空间
若你真的有发布的需求，请联系管理员merge你的代码后进行发布处理
一、手动发布 SPEC 规范包：@ant-yasa/uast-spec
该包定义了 UAST 的通用结构规范，是 JS/TS 生态的基础依赖。

[[CARD_32]]
```plain
cd specification/
```
步骤 1：安装 Node.js 环境（前提）
确保已安装：
Node.js ≥18
npm（随 Node 自带）
已登录 NPM CLI

[[CARD_33]]
```plain
npm login --registry=https://registry.npmjs.org
# 按提示输入用户名、密码、邮箱（需为 NPM 官方账号）
```
步骤 2：设置要发布的版本号
假设你要发布 v1.2.3（注意去掉 v 前缀）：

[[CARD_34]]
```plain
VERSION="1.2.3"
```
步骤 3：检查是否已存在该版本

[[CARD_35]]
```plain
npm view @ant-yasa/uast-spec@$VERSION version
```
如果返回版本号，说明已存在，请勿重复发布；
如果提示“not found”，则继续。
步骤 4：安装依赖并构建

[[CARD_36]]
```plain
npm install
npm run build
```
✅ 构建成功后应生成：

[[CARD_37]]
```plain
dist/index.js
dist/index.d.ts
```
步骤 5：校验打包内容
运行 dry-run 查看即将上传的内容：

[[CARD_38]]
```plain
npm pack --dry-run
```
确认输出中包含：

[[CARD_39]]
```plain
dist/index.js
dist/index.d.ts
```
❌ 如果未出现 dist/ 目录文件，请检查 .npmignore 或 files 字段是否误排除。
步骤 6：更新 package.json 版本

[[CARD_40]]
```plain
npm version $VERSION --no-git-tag-version
```
这会自动修改 package.json 中的 "version" 字段，但不会创建 Git Tag。
步骤 7：选择标签并发布
根据版本性质选择 NPM 标签：
|
版本格式
|
示例
|
NPM Tag
|
正式版
|
0.1.21
|
latest
|
测试版
|
0.1.21-beta.1
|
beta
执行发布：

[[CARD_41]]
```plain
# 发布正式版
npm publish --tag latest

# 或发布 beta 版
npm publish --tag beta
```
✅ 验证发布结果
访问：
👉 https://www.npmjs.com/package/@ant-yasa/uast-spec
确认新版本已列出。

[[CARD_42]]
二、手动发布 Java-Js 解析器：@ant-yasa/uast-parser-java-js
该包提供 Java 和 JavaScript 代码的 UAST 解析能力，依赖于 @ant-yasa/uast-spec。
📍 路径

[[CARD_43]]
```plain
cd parser-Java-Js/
```
步骤 1：确保 SPEC 已发布
在发布本包前，必须确认 @ant-yasa/uast-spec@$VERSION 已在 NPM 上可用。
测试命令：

[[CARD_44]]
```plain
npm view @ant-yasa/uast-spec@$VERSION version
```
替换 $VERSION 为你正在发布的版本（如 1.2.3）；
若无输出，请等待或重新发布 SPEC。
步骤 2：清理并安装依赖

[[CARD_45]]
```plain
rm -rf node_modules package-lock.json
npm install
```
步骤 3：显式安装目标版本的 SPEC

[[CARD_46]]
```plain
npm install @ant-yasa/uast-spec@$VERSION --no-save
```
使用 --no-save 是因为这只是构建时依赖，不应写入 package.json。
步骤 4：构建项目

[[CARD_47]]
```plain
npm run build
```
✅ 构建成功后应生成：

[[CARD_48]]
```plain
dist/src/index.js
```
步骤 5：更新版本并发布

[[CARD_49]]
```plain
npm version $VERSION --no-git-tag-version
npm publish --tag latest # 或 --tag beta
```
