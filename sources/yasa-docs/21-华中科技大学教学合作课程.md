# 华中科技大学教学合作课程

2025年11月7日，蚂蚁基础安全团队与华中科技大学（以下简称华科）网络空间安全学院联合开设的研究生课程《静态程序分析原理与实践》正式开课。该课程主要面向华科软件安全方向的研究生同学，采用理论与实践相结合的教学模式，旨在培养具备扎实理论基础和强实践能力的网络安全专业人才。
