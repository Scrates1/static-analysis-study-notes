# 污点分析

执行命令示例

[[CARD_01]]
```plain
# js语言命令示例
/Users/yasa-macos-arm64
--sourcePath /Users/.../ant-application-security-testing-benchmark
--checkerPackIds taint-flow-javascript-default
--language javascript
--report ./reportaaa/a/b
--ruleConfigFile /Users/rule_config.json

# go语言命令执行
/Users/yasa-macos-arm64
--checkerPackIds taint-flow-golang-default
--analyzer GoAnalyzer
--ruleConfigFile /Users/rule_config_go.json
--sourcePath /Users/.../xxx
--uastSDKPath /Users/uast4go/uast4go
--report ./reportaaa/a/b
```
说明：
执行go或则python语言分析时，需指定uast4go和uast4python的二进制路径。js已集成在yasa内，不需要指定
参数说明

[[CARD_02]]
```javascript
--help 打印帮助
--sourcePath 将要分析的目标文件
--language 设定语言，单选，目前支持'javascript', 'typescript', 'golang', 'python'
--analyzer 设定分析器，单选，目前支持 EggAnalyzer (Egg框架) | JavaScriptAnalyzer | GoAnalyzer（支持gin、mux、grpc） | PythonAnalyzer (支持flask、fastmcp、Triton框架)。如果设置了analyzer，就无需要再设置langugae
--report 指定输出报告目录
--uastSDKPath go/python语言分析时必填，指定uast4go和uast4python的二进制路径
--ruleConfigFile 指定ruleConfig文件目录，绑定污点追踪功能需要
--checkerPackIds 规则包指定，规则包选择可见内置checker介绍
--checkerIds 规则指定，规则选择可见内置checker介绍
--entrypointMode entrypoint模式，默认BOTH （yasa自采集+外部传入）｜ SELF_COLLECT（yasa自采集）｜ ONLY_CUSTOM（只外部传入）
* source自采集范围：支持框架的source （egg、gin、mux、grpc、flask、fastmcp、Triton）
* entrypoint自采集范围：支持框架的entrypoint（egg、gin、mux、grpc、flask、fastmcp、Triton）、语言默认entrypoint（js、go、python生效）、callgraph边界（全语言生效）
```
配置ruleConfigFile
修改ruleConfig文件，无需打包，可直接执行，具体包括source/sink/sanitizer/entrypoint，配置方式见这里，其中内置检测规则（checker）介绍点这里。也可以查看release包中的ruleconfig示例。
