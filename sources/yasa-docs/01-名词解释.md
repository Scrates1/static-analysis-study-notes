# 名词解释

YASA 名词解释
|
名词
|
全称
|
解释
|
YASA
|
Yet Another Static Analyzer
|
本项目名称。包括YASA-UAST、YASA-Engine、YASA-UQL、YASA-MCP四部分。
|
UAST
|
Unified Abstract Syntax Tree
|
统一抽象语法树，解析器将不同语言文件解析到同一套AST结构（UAST）中。YASA针对UAST进行建模分析，就具备了多语言静态分析通用的能力。
|
UQL
|
Unified Query Language Library
|
统一声明式规则查询语言。包括QL语言及编译器、UQL查询标准库
|
xAST
|

|
开源的SAST/IAST/DAST工具能力评测体系，详见链接。在YASA中作为变更后测试所用的回归靶场。
|
符号解释

|

|
YASA将AST节点符号化，进行模拟执行的过程。
|
checker
|

|
检查器。支持用户自定义，在符号解释的过程中触发，执行用户的自定义计算/采集/检查等操作。在YASA中默认提供了一些checker，功能主要集中在污点分析、callgraph生成、sanitizer判断、entrypoint采集等。
|
checker-pack
|

|
检查器组，即一些checker的合集。YASA将目前有的checker按场景封装到了pack里，供用户直接选择。
|
checkpoint
|

|
检查点，分布于整个符号解释的过程。检查器中会触发各种类型的检查点，在模拟执行到特定AST节点时，执行checker中用户指定的分析操作。
|
污点分析
|

|
从一个source点（污点变量）开始，经过一系列数据传播过程最后传播到sink点的过程。
|
entrypoint
|

|
YASA进行符号解释的起点，可以由用户指定也可以YASA根据策略自主采集，如框架特定entrypoint（web框架的router）、callgraph的边界、文件的第一行、用户指定的特定文件的特定函数。
