# 进阶-如何使用YASA支持新的框架做污点分析

背景：YASA 如何快速支持新框架完成污点分析
高级语言（如Java/js/go等）中提供许多web框架（如go gin框架），来为开发者提供构建Client-Server模型项目的能力。开发者能够通过特定的路由注册语句，指定一个函数作为对外可见的路由函数(即YASA中的entrypoint)，外部用户能够直接将请求发送至路由函数，从而访问项目的服务，例如：

[[CARD_01]]
```go
r.GET("/user", getUser) // “getUser”即为entrypoint
```

YASA作为基于模拟执行的静态程序分析引擎，需要从程序的entrypoint开始模拟执行。为了正确找到entrypoint，YASA需要对这些web框架的路由注册方式进行适配支持，并将能被外部用户控制的数据(Request)标记为source。
简而言之，YASA支持web框架的关键点为：
1️⃣ 识别路由注册方式并自采集被注册的路由函数作为entrypoint
2️⃣ 将外部可控的数据结构标为source
3️⃣ 识别并标记传播链路中的sanitizer/sink
对于3️⃣，YASA提供了语言原生常见的sanitizer和sink，并封装了TaintChecker，若您有支持新框架的需求，只需完成1️⃣和2️⃣即可。
