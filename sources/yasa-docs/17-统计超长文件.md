# 简单-如何使用YASA统计每一个超过200行文件的行数

首先，你需要新建一个checker继承自checker基类，并在构造函数中指定checkerId，同时传resultManager用于承载finding

[[CARD_01]]
```javascript
class LocCalChecker extends Checker{
constructor(resultManager){
super(resultManager, 'LocCalChecker')
}
}
```

第二步，根据需求，判断函数是不是空，那么在每一个文件模拟执行时进行check，使用triggerAtCompileUnit即可。

[[CARD_02]]
```javascript
triggerAtCompileUnit(analyzer, scope, node, state, info){
if (!node || !node.loc) return;
if (node.loc.end.line - node.loc.start.line >= 200) { //判断是不是超过200行
const finding = {
filename: node.loc.sourcefile
length: node.loc.end.line - node.loc.start.line
}
this.resultManager.newFinding(finding,LocCalCheckerStrategy.outputStrategyId) //outputStrategyId 需要指定，见下文
}
}
```
第三步，现在我们记录了finding，还需要指定如何打印finding，YASA将如何记录finding、打印finding的权利都交给了用户，可以灵活的打印自己需要的格式。我们需要实现一个strategy，放在src/checker/common/output 目录下，继承自OutputStrategy。
接下来我们在strategy中定义outputFindings函数，YASA将在分析结束后调用这个函数对你的finding进行个性化的输出。

[[CARD_03]]
```javascript
class LocCalCheckerStrategy extends OutputStrategy {
//需要定义一个outputStrategyId，在this.resultManager.finding中传入。
static outputStrategyId = 'LocCalCheckerStrategy'

constructor() {
super()
this.outputFilePath = 'xxx.json'//若要在文件中输出，这里可以定义
}

outputFindings(resultManager, outputFilePath, config, printf){
const allFindings = resultManager.getFindings()
const finding = allFindings[LocCalCheckerStrategy.outputStrategyId]
//这里喜欢的话可以获取其他的outputStrategyId组合到一个报告里
finding.forEach(info => {
console.log(`filename:${info.filename}, file content length:${info.length}`)
}
//使用outputFilePath也可以将它输出到文件
//...
}
}
```
最后，你需要将你的checker注册到YASA上，注册方式在resource/checker/checker-config.json中，如下。由于这个checker不需要外部的输入，就不需要指定demoRuleConfigPath了。

[[CARD_04]]
```json
{
"checkerId": "LocCalCheckerChecker",
"checkerPath": "src/checker/locCalCheckerChecker.js",
"description": "寻找代码中大于200行的文件",
}
```
注册好后，就可以通过--checkerIds来指定这个checker运行了，也可以制作一个规则包，将这个checker放进去和其他checker一起运行，注册到resource/checker/checker-pack-config.json中，就可以通过--checkerPackIds来指定这个规则包了
