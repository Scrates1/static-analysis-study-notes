# YASA 官方文档快照

本目录保留 YASA 官方公开语雀知识库的规范化研究快照，作为实验笔记的可追踪证据。

- 官方知识库：<https://www.yuque.com/u22090306/bebf6g>
- 文档数量：21
- `01-*.md`～`21-*.md`：规范化正文，front matter 保留标题、slug、原始 URL、官方更新时间和统计信息；
- `*.assets.json`：正文出现的链接、图片 URL、代码/附件/图示卡片元数据；
- `index.json`：全部文档的来源、更新时间及本地路径索引。

更新命令：

```bash
python scripts/fetch_yasa_docs.py
```

该脚本默认刷新本目录。第二、三讲 PDF 附件在匿名访问时返回登录页，因此这里只保存可核验的附件名称和官方链接，不把登录 HTML 冒充 PDF 正文。

这些文件用于研究、核验和课程学习，不替代官方在线文档；向公开 Git 仓库再分发前仍应核对上游许可并保留来源归属。
