# 操作手册

使用约束
当前支持
单文件分析/文件目录分析
不支持压缩文件
语言：Go、Python、JavaScript
功能概述
|
功能点
|
功能描述
|
AST解析
|
获取单个文件的AST信息
支持语言：js/ts、go、python，不支持同时检测多种语言
仅支持单文件
|
获取目标代码中全部的call graph
|
获取目标代码中所有的call graph
支持语言：js/ts、go、python，不支持同时检测多种语言
|
获取目标代码中的污点链路数据
|
根据配置信息，获取目标代码中的污点链路数据
支持语言：js/ts、go、python，不支持同时检测多种语言
其中Go语言仅支持检测单模块项目，即一个项目只有一个go.mod
|
自定义分析
|
通过自定义编写Checker来实现自定义的程序分析能力。
执行命令与参数说明
通过YASA执行命令调用YASA二进制文件
执行命令
yasaSDK [--option1 xxx --options2 xxx ...] target_directory/target_file

示例：

[[CARD_01]]
```bash
# 检测eggbenchmark的污点链路，链路source/sink点配置：./Downloads/eggbenchmark.json
./yasa-macos-arm64 --ruleConfigFile ./Downloads/eggbenchmark.json --analyzer EggAnalyzer --checkerPath ./src/checker/taint/js ./EggProject/eggbenchmark/

# 获取 root.go文件的抽象语法树（AST）
./yasa-macos-arm64 ./GoProject/cmd/root.go --language golang --uastSDKPath ./uast/uast4gomacosarm/uast4go-macos --dumpAST

# 获取 ant-application-security-testing-benchmark 代码库的完整call graph
./yasa-macos-arm64 ./ant-application-security-testing-benchmark --analyzer JavaAnalyzer -dumpAllCG
```
